# docs/

External reference material — datasheets, hardware docs, third-party manuals.

When fetching a datasheet or hardware document for any reason (Claude or otherwise),
drop it here rather than into a tool-results scratch directory. Use a friendly filename
(`pico-2-w-datasheet.pdf`, not the publisher's internal `RP-008304-DS-2-…` name) and
prefer PDFs over screenshots.

This directory is **not** for project-internal documentation — that lives at the repo
root (`ARCHITECTURE.md`, `TODO.md`, `_familiarization/`) or per-subsystem.
