Getting the FT232H set up for this code: (from the Microsoft Iot.Device.Bindings page found here: https://github.com/dotnet/iot/tree/main/src/devices/Ft232H)

* Install the FTDI D2XX drivers found here: https://ftdichip.com/drivers/d2xx-drivers/
* Several of the Adafruit FT232H breakout boards that I bought have the same Serial number.  They can be reprogrammed by following these instructions:
  * https://electronics.stackexchange.com/questions/529524/uniquely-identifying-ft232h-chips
  * Here is the programming utility page: https://ftdichip.com/utilities/#FT_PROG
