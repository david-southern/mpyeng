* Update Reactor:

** for all batteries, increase/reduce the `batteryChargeLevel` according to the `level` value, multiplied by the `batteryChargeRate`
** clamp battery charge leven to [0, 1]
* If the new charge level is changed from the old charge level than 'handleEvent': `reactorBatteryChargeLevel`

  subscription ReactorUpdate($simulatorId: ID) {
    reactorUpdate(simulatorId: $simulatorId) {
      id
      model
      batteryChargeLevel
      efficiency
      powerOutput
      hasWings
      leftWingPower
      leftWingRequest
      leftWingRequested
      rightWingPower
      rightWingRequest
      rightWingRequested
    }
  }
`;

Battery power available: Reactor.batteryChargeLevel - values of [0, 1.0]
Reactor actual power output: Reactor.powerOutput * Reactor.efficiency

Power is consumed by Systems that have a powerLevels array with at least one element:
export const SYSTEMS_SUB = gql`
  subscription SystemsUpdate($simulatorId: ID) {
    systemsUpdate(simulatorId: $simulatorId, power: true) {
      id
      displayName
      type
      wing
      power {
        power
        powerLevels
      }
      damage {
        damaged
      }
    }
  }
`;

System.power.power = Current system power allocation
System.power.powerLevels = required power allocation for each level of output - powerLevels[0] is the minimum power required for the system to function at all.
