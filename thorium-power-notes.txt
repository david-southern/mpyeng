Overall interactions to consider:
* System.power is manipulated on the PowerDistribution view - It calls the systemPowerMutation for each system whenever the power allocation for the system is changed.  There does not appear to be any limit on what the kids can set the power to, beyond the view limit of a max of 40 power per system.  
** Note: The power allocation controls are not limited by "available power" the kids can assign more power than is available.  Need to find out how this is accounted for.

* Each system has a `power` value - power allocated to this system and a `powerLevels` value - an array of required power allocations for different levels of system functionality.
** The base System object has `setPower` and `setPowerLevels` methods that track the `this.power` and `this.powerLevels` values, but does not do anything else,

* There is a system named "Crm" (something about sending out fighters) that has a "setPower" method.  In this method, if the power is set to a value less than `this.powerLevels[0]`, then the system `this.activated` is set to false, no other action is taken, and powerLevels is not considered anywhere else in this system.  Perhaps the system only has a single power level.

Power is produced by Reactors:
Two types of Reactors: model="reactor" and model="battery"

Battery power available: Reactor.batteryChargeLevel - values of [0, 1.0]
Reactor actual power output: Reactor.powerOutput * Reactor.efficiency

Power is consumed by Systems that have a powerLevels array with at least one element:
export const SYSTEMS_SUB = gql`
  subscription SystemsUpdate($simulatorId: ID) {
    systemsUpdate(simulatorId: $simulatorId, power: true) {
      id
      displayName
      type
      wing
      power {
        power
        powerLevels
      }
      damage {
        damaged
      }
    }
  }
`;

System.power.power = Current system power allocation
System.power.powerLevels = required power allocation for each level of output - powerLevels[0] is the minimum power required for the system to function at all.
